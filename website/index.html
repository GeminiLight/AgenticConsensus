THE APPROACH

Give collaboration a shared state.

A conversation can explain a change. A project also needs a record of its requirements, the version that was checked, and who authorized the next step.

01

Preserve intent

Keep the original request, candidate interpretations, and clarifications attached to the proposed change.

02

Bind the evidence

Inspect code and test results against declared requirements. See missing checks and evidence from an older revision.

03

Record the decision

Apply project authority and version checks before an authorized person records a decision in the audit trail.

git clone https://github.com/GeminiLight/AgenticConsensus.git
cd AgenticConsensus
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/agentic-consensus demo --reset
.venv/bin/agentic-consensus serve

Open http://127.0.0.1:8765. Create the first account with the demo audit identity security-lead@example.test.

To reopen your workspace, run serve again. demo --reset rebuilds the demo data.
