Current research summary +

Code records what was built. It does not, by itself, explain the choices a project has agreed to preserve. AgenticConsensus links intent, commitments, artifacts, and evidence in a versioned project state that people and agents can inspect and revise.

Agreed changes guide implementation. Updated artifacts reveal conflicts, gaps, and stale evidence. Consensus Control puts this approach into a review workspace, with humans retaining decision authority.

A few useful distinctions

Before you dive in.

Is consensus a vote between agents?+

No. Consensus is the authorized project state, including unresolved claims and scoped exceptions. Agent agreement alone does not establish truth or grant permission.

How does this relate to code review?+

It connects a diff to the commitments it affects, the intent behind it, and the evidence that still applies. Your existing code review gains a shared project context.

What can I run today?+

Consensus Control supports local review, read-only GitHub PR import, source inspection, evidence requirements, and authorized decisions. Automated analysis covers Python imports; executable changes are currently limited to a single import substitution.

Does approval merge my GitHub pull request?+

No. Approval updates local project state and its audit history. The read-only GitHub connection cannot push code or merge a PR.
